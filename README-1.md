# صفحه‌ی لینک‌ها (Link in Bio) فارسی

یک صفحه‌ی ساده برای گذاشتن همه‌ی لینک‌هایتان در بیوی اینستاگرام، تلگرام یا یوتیوب. **HTML و CSS خالص**، راست‌چین، مناسب موبایل و با حالت تاریک خودکار.

## ویژگی‌ها
- راست‌چین کامل با فونت وزیرمتن
- مخصوص موبایل (جایی که بیشتر بازدیدها از آن است)
- حالت تاریک خودکار
- بدون جاوااسکریپت؛ بسیار سریع

## شخصی‌سازی
1. در `index.html` اسم و توضیح را بنویسید
2. آدرس هر لینک را عوض کنید (`USERNAME` را با یوزرنیم خودتان جایگزین کنید)
3. لینک جدید می‌خواهید؟ یک بلوک `<li>` را کپی کنید
4. رنگ‌ها بالای `style.css` در بخش `:root` هستند
5. برای عکس پروفایل، `<span class="avatar">` را با `<img src="me.jpg" alt="نام شما">` عوض کنید

## انتشار رایگان
Settings ← Pages ← Branch: `main` ← Save

بعد از چند دقیقه آدرس سایت را می‌گیرید؛ همان را در بیوی اینستاگرام بگذارید.
